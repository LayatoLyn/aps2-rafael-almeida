Titulo: Uso do Apache Kafka

Status: [Aprovado]

Problema tecnico a ser resolvido: 
O sistema de monitoramento IoT precisa identificar possíveis anomalias nas máquinas industriais e encaminhar essas informações para o Gerenciador de Alertas, responsável por registrar e disponibilizar as notificações no Grafana.

Como o sistema recebe dados constantemente dos sensores de temperatura e vibração, é necessário utilizar uma solução que consiga transmitir grandes quantidades de mensagens sem exigir uma comunicação direta e simultânea entre os componentes.

Além disso, caso o Gerenciador de Alertas esteja temporariamente indisponível, é importante que os eventos de anomalia não sejam simplesmente perdidos.

Decisão:

Foi escolido o Kafka porque ele permite a transmissão assíncrona de mensagens, possibilitando que os componentes trabalhem de maneira independente. E será utilizado um tópico chamado anomalias-detectadas, responsável por armazenar e distribuir os eventos identificados pelo algoritmo preditivo.

O Analisador Preditivo será responsável por publicar os eventos nesse tópico, enquanto o Gerenciador de Alertas será responsável por consumi-los e iniciar o processo de geração das notificações.

Consequências:

Vantagens:
- Permite a comunicação assíncrona entre os componentes do sistema.
- Permite armazenar mensagens temporariamente para consumo posterior.
- Possibilita lidar melhor com grandes volumes de dados provenientes dos sensores.
Débitos técnicos e riscos aceitos:
- A implementação e configuração do Kafka aumentam a complexidade da infraestrutura.
- É necessário monitorar o funcionamento dos tópicos e consumidores.
- Podem ocorrer atrasos entre a identificação da anomalia e a exibição do alerta.

Justificativa final:

A utilização do Apache Kafka foi considerada adequada porque o projeto trabalha com transmissão constante de dados e precisa garantir maior independência entre os componentes responsáveis pela análise e pela geração de alertas. Mesmo adicionando complexidade à estrutura do projeto, a tecnologia oferece recursos importantes para a distribuição de mensagens e permite que o sistema seja ampliado futuramente.
